## 📖 Sobre

Sistema de raspadinha em PHP com compra de cartelas, prêmios, pagamentos PIX via Ecompag, webhook automático e painel administrativo.

## ✨ Recursos

| Módulo | Descrição |
|---|---|
| Raspadinha | Cartelas com prêmios |
| PIX Ecompag | Client ID e Client Secret |
| Webhook | Confirmação automática de pagamento |
| Admin | Gestão de prêmios, usuários e saques |
| Banco | Configuração em `conexao.php` |
| Histórico | Cartelas e resultados |

## 📦 Instalação

1. Envie os arquivos para a hospedagem (PHP 8+ e MySQL/MariaDB).
2. Crie o banco e importe o SQL do pacote.
3. Configure o banco em `conexao.php`.
4. Acesse o administrativo com `admin@eu.com` / `qwe123#` e **troque a senha**.
5. No gateway, cole o Client ID e o Client Secret da [Ecompag](https://ecompag.com).
